# CFMIX Landing Page

Landing page institucional desenvolvida para uma empresa do setor de **bombeamento de concreto**, com foco em apresentar a empresa, seus serviços e facilitar o contato com potenciais clientes.

## Sobre o projeto

O projeto foi desenvolvido como uma **landing page profissional para a CFMIX**, buscando criar uma presença digital moderna, objetiva e responsiva.

A página tem como principais objetivos:

* Apresentar a empresa e seus serviços;
* Destacar os diferenciais da empresa;
* Facilitar o contato com clientes;
* Gerar potenciais leads;
* Oferecer uma experiência responsiva em diferentes dispositivos;
* Melhorar a presença digital da empresa.

## Como executar

### Pré-requisitos

* Node.js
* npm

### Instalação

Clone o repositório:

```bash
git clone https://github.com/pietros133/cfmix-landing_page.git
```

Entre na pasta:

```bash
cd cfmix-landing_page
```

Instale as dependências:

```bash
npm install
```

### Desenvolvimento

Execute o projeto:

```bash
npm run dev
```

O Vite iniciará o servidor de desenvolvimento e exibirá a URL para acessar a aplicação.

### Build de produção

Para gerar o build:

```bash
npm run build
```

Para visualizar o build localmente:

```bash
npm run preview
```
